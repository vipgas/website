# Gas Engineer Business Website

A modern, responsive website for a professional gas engineering business. This website is designed to showcase services, provide company information, and allow customers to get in touch easily.

## Features

- Modern, responsive design
- Service showcase
- About us page with team information
- Contact form
- Mobile-friendly navigation
- Professional styling

## Pages

1. **Home Page**
   - Hero section with call-to-action
   - Services overview
   - Why choose us section
   - Contact information

2. **Services Page**
   - Detailed service descriptions
   - Service features and benefits
   - Call-to-action for quotes

3. **About Page**
   - Company introduction
   - Team members
   - Company values
   - Certifications
   - Customer testimonials

4. **Contact Page**
   - Contact form
   - Business information
   - Location map
   - Emergency contact details

## Setup Instructions

1. Clone the repository:
   ```bash
   git clone [repository-url]
   ```

2. Navigate to the project directory:
   ```bash
   cd gas-engineer-website
   ```

3. Open `index.html` in your web browser to view the website.

## Customization

### Images
- Replace placeholder images in the `images/` directory with your own:
  - `hero-bg.jpg`
  - `services-bg.jpg`
  - `about-bg.jpg`
  - `contact-bg.jpg`
  - `team-1.jpg`, `team-2.jpg`, `team-3.jpg`
  - `gas-safe.png`
  - `iso-9001.png`
  - `trusted-trader.png`

### Content
- Update text content in HTML files to match your business information
- Modify contact details throughout the website
- Add your own testimonials
- Update service descriptions

### Styling
- Colors can be modified in `css/styles.css`
- Main color scheme:
  - Primary: #3498db
  - Secondary: #2c3e50
  - Background: #f9f9f9

## Technical Details

### Dependencies
- Font Awesome 6.0.0 (CDN)
- Custom CSS
- Vanilla JavaScript

### Browser Support
- Chrome (latest)
- Firefox (latest)
- Safari (latest)
- Edge (latest)

### Responsive Breakpoints
- Mobile: < 768px
- Tablet: 768px - 1024px
- Desktop: > 1024px

## Deployment

The website is designed to be deployed on GitHub Pages or any static web hosting service.

To deploy on GitHub Pages:
1. Push the code to your GitHub repository
2. Go to repository settings
3. Navigate to GitHub Pages section
4. Select main branch as source
5. Save the settings
